# Propostas de hotsite — Secretaria Municipal de Cultura de Jaguariúna

Protótipo para avaliação visual, com três direções distintas e uma página-índice. Não é o site oficial da Prefeitura. Não há cookies, rastreadores nem envio de dados no formulário de contato (é só demonstração).

Conteúdo marcado como "a confirmar" ainda não é dado oficial definitivo.
